# 主張マップ(様式 v1 — 2026-08-12 研究者批准)

運用規則:
- 1行 = 論文中の1主張。**主張文・水準・枠組み対応の記入と変更は研究者のみ**。
  Claude Code の役割は写像検査(マップ↔本文↔台帳の突き合わせ)に限る。
- 状態遷移: `draft`(記入済み)→ `ratified`(研究者批准)→ `frozen`(本文反映+数値照合済み)。
  ratified 以降の変更は理由を「改訂メモ」に残す(amendment 文化と同型)。
- 執筆順序は Methods → Results → Discussion/Intro → Abstract。Intro の「予告」列と
  Discussion の「受け」列が空欄のまま frozen にしない(空欄=未接続の検出器)。

## 列定義

| 列 | 内容 |
|---|---|
| ID | C-01, C-02, …(節をまたいで通し番号) |
| 節 | Results §x.y(主たる居場所) |
| 主張文 | 1行。A/B中立文言の制約(計画v2 §0.5 第6回)に服す |
| unit/規則 | 対応 unit と、該当する場合はパターン規則番号(計画v2 §0.6 の 1–7) |
| 水準 | `主張` / `記述的観察` / `仮説生成`(§0.5 の水準制約に従う。REO 段階性は記述的、探索セル産は仮説生成のみ) |
| 根拠 | 数値台帳ID(N-xx, 複数可)+ 図表番号 |
| Intro予告 | Intro のどこで予告するか(なし=なしと明記) |
| Disc受け | Discussion のどの段落が受けるか |
| 状態 | draft / ratified / frozen |

## 執筆リント(批准済み制約からの機械的チェック項目 — 全稿に適用)

1. unit 横断の研究全体 FDR を主張しない。「いずれかの unit で有意」型の文を書かない(§0.6)
2. 主張の文言は A/B 中立(§0.5 第6回の非識別性。非識別性自体は limitation に明文化)
3. 線量依存性を仮定・主張しない。REO の段階性は記述的観察の水準(§0.5 第1回)
4. q<0.25 を探索的基準としても使用しない(§0.3)
5. B_Tumor が null でも「特異性確認」と書かない(§0.5 第3回ガードレール)
6. 探索セル(非層別対比)由来の内容は仮説生成としてのみ報告(§0.5 第6回昇格規則)
7. 年齢について「p>0.05 なので差がない」スタイルを採らない(§0.5 第2回)
8. 本文中の全数値は数値台帳(N-ID)経由で出典に辿れること(手打ち数値の禁止)
9. Westfall–Young FWER は本文・図表に使用しない(§0.3)
10. 主張水準は控えめ制約(ウェット追試不能・REO の中間データ依存)を超えない(§0.5 第1回)

## 検査運用(いつ・何を回すか)

- **トリガー1(節単位)**: ある節を frozen にする時点で、(a) その節の全主張がマップの ratified 行に対応、(b) 執筆リント10項目、(c) 節内の全数値が N-ID タグ付きで台帳と一致、を検査してから frozen にする。
- **トリガー2(投稿前)**: 全文一括で同じ検査+Intro予告/Disc受け列の空欄ゼロ確認+用語一貫(unit名・AS帯・コホート名の表記ゆれ)を実施。
- **紐付け機構**: 原稿ソースには数値の直後にコメントタグ(`<!-- N-07 -->`、主張段落の冒頭に `<!-- C-03 -->`)を埋める。投稿版の生成時に機械的に除去する(除去スクリプトは paper/ に置く)。タグがない数値・主張段落はリント違反として検出する。
- 検査の実施者は Claude Code、判定の最終責任と修正の裁量は研究者。
