# 主張マップ(様式 v1 — 2026-08-12 研究者批准)

運用規則:

- 1行 = 論文中の1主張。**draft の下書きは Claude Code が行ってよい**が、根拠は
  正典(計画v2 §0.5/§0.6)と確定数値(B.14)に限り、そこから逸脱する主張を創作しない。
  機械的に決まらない判断点は行を埋めず【要研究者判断】として列挙する。
  **ratified への昇格・修正・水準の最終決定は研究者のみ**。
  Claude Code のもう一つの役割は写像検査(マップ↔本文↔台帳の突き合わせ)。
- 状態遷移: `draft`(記入済み)→ `ratified`(研究者批准)→ `frozen`(本文反映+数値照合済み)。
  ratified 以降の変更は理由を「改訂メモ」に残す(amendment 文化と同型)。
- 執筆順序は Methods → Results → Discussion/Intro → Abstract。Intro の「予告」列と
  Discussion の「受け」列が空欄のまま frozen にしない(空欄=未接続の検出器)。
- **本マップは足場(検査機構)である**(2026-08-14、3バケツ整理): 主張↔本文↔台帳の
  写像検査のための装置であり、採録確定まで併走した後に削除する(履歴は git)。
  残すべき決定と事由は論文本文へ、不発記録と反論素材は手元台帳(objections_ledger)へ収束。
