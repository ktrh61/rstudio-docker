# 手元台帳(反論+不発記録。様式 v1 — 2026-08-12 研究者批准、2026-08-14 拡張)

運用規則:

- 想定される指摘(共著者・査読者)と回答方針・根拠の所在を1行1件で貯める(Q 節)。
- **拡張(2026-08-14、研究者批准の3バケツ整理)**: 論文に残すべき決定と事由は論文本文
  (本文+Supp)へ収束させる(バケツ1)。本台帳はバケツ2(試したが不発・検討済み不採用 =
  T 節)とバケツ3(想定反論への回答 = Q 節)の**統合された唯一の待機所**。
- **3要件**: (i) 数値を引くエントリは証拠等級(本番系実測 / 設計時来歴 / 文献)を携行する。
  (ii) 論文に載らない数値は出典を**自蔵**する(numbers_ledger は足場であり採録確定後に
  削除されるため、死後も辿れる形 — git show 参照・保全物パス等 — で書く)。
  (iii) 保全成果物はパスで指す(中身を複製しない)。
- **昇格の逆流**: リバイスで論文へ昇格したエントリは昇格先(節・Supp 番号)を記して閉じる。
  本台帳は墓場ではなく待機所。
- **足場との関係**: claim_map・numbers_ledger は検査機構(足場)で、採録確定まで併走した後
  削除する(履歴は git)。本台帳はリバイス終了まで生きる。
- **計画v2 からの移送**: T 節のエントリが批准されたら、計画v2 側の該当記述は削る
  (計画v2 はリポジトリ外の作業用メモ相当 — 徐々に空へ収束)。
- 計画v2 §0.5 に批准済みの想定問答が既にあるため、初期4件はそこからの転記(Q-01〜Q-04)。

## 証拠の階層(2026-08-12。Q・T 全節共通)

較正・妥当性の**負荷を担う証拠は本番系のみ**: D6 較正(本番 pooled global-null 0.064 = N-56。採用時測定 0.045 = N-57 と tail-ratio 系の棄却 0.140/0.221 = N-58 は実データ前の選定記録)と spike-in(回収+偽陽性余剰ゼロ)— 本番系は正準入力・B.14 凍結。
opus5 セッション(2026-08-07 の GSEA 仕様検証)の実測値は**設計選択の来歴**であり、負荷を担わせない(研究者による同セッションの計算品質評価を受けた格付け)。最終機構は D6+spike-in により端から端まで独立に再検証済みのため、防御は opus5 の品質に依存しない。
