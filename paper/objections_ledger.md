# 反論台帳(様式 v1 — 2026-08-12 研究者批准)

運用規則:
- 想定される指摘(共著者・査読者)と回答方針・根拠の所在を1行1件で貯める。
- 「論文=正本」に収束させる方針の下で、**論文に載らないが捨てられない素材の唯一の置き場**。
- 「先回り」列は、論文内で先回りして書くか(どこで)、手元回答に留めるかを事前に決める。
- 計画v2 §0.5 に批准済みの想定問答が既にあるため、初期4件はそこからの転記(Q-01〜Q-04)。

## 列定義

| 列 | 内容 |
|---|---|
| Q-ID | Q-01, Q-02, … |
| 想定指摘 | 指摘の要約1行 |
| 回答方針 | 1〜2行 |
| 根拠の所在 | 計画v2 B.x/§、文献DOI、diagnostics、保全物パスなど |
| 先回り | 論文内(節を明記)/ 手元のみ |
| 状態 | draft / ratified |
