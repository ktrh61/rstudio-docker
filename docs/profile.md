## 区画2：研究ドメイン前提（research knowledge）

外部の証拠（文献・データ・統計理論）が決める確定した研究知見。運用者の裁量では動かせないため、[decisions](decisions.md) ではなくここに置く。

- **Results 分離規律**: 本区画は恒常前提のみを記す。Results（解析で得られた数値：DEG 数・症例数・サンプル数・感度/特異度・分類器の規模等）は書かない。Results は再実装で動き得るため、前提として固定すると再解析時に破綻する。Results の所在は論文本体・解析出力であり、恒常前提ではない。数値の確定・更新は [decisions](decisions.md)／[worklog](worklog.md)／論文本体が扱う。

- **研究目的**: 放射線関連甲状腺癌において、driver 変異依存の発現シグネチャを同定し、RET 融合陽性例で放射線誘発性と散発性を判別する REO 分類器を構築する。
- **データ**: NCI GDC の REBC-THYR コホート由来。（サンプル数・症例数・GDC リリース番号は解析パイプラインの産物または実行時取得値であり、恒常前提として固定しない。リリース番号は `status()$data_release` で取得する方針で、確定は 01 改修時 → worklog A。）
- **群設計**: 4群（R0/R1＝RET 融合群、B0/B1＝BRAF 変異群）。
- **R1 群の不均一性**: R1 は放射線誘発性と散発性が混在する非均一群である。REO はこの R1 内の放射線誘発サブセットの検出を狙う。
- **driver-specificity**: BRAF V600E は散発性癌と関連し、RET 融合は放射線誘発癌と関連する（文献支持）。この driver 依存性により、放射線誘発性と散発性で発現シグネチャに差が生じることが本研究の設計前提である（具体的な DEG 数は Results であり本区画には記さない）。
- **確定した手法**: DEGES-MUREN 統合正規化、Brunner-Munzel 検定＋BH 補正による DEG 解析、GSEA 一本化（ORA 廃止）、delta 主体ランキング（p 値タイブレーク）。
- **REO パネル**: Relative Expression Ordering（REO、相対発現順序）に基づく分類器を構築する。遺伝子ペア数や特異度等の数値は Results であり本区画には記さない。

（MUREN 参照選択の是正方針、gls.cpp の結果影響評価など、議論中・検証待ちのものはここに入れず [worklog](worklog.md) に置く。）
